# Deliverable 06: Belief-Ready Audience Analysis

**Langfell™ Belief Shift Strategy**
**Phase 2: Audience & Brand Positioning**
**v4.2 | Statement-Based Architecture**

---

## Identity & Purpose

Define the audience by belief-readiness. Map which statements meet which stage.

---

## Inputs Required (from Module 05)

```text
- Filter (Who we're for / not for)
- Belief Shift (FROM → TO)
- Brand Voice
```

---

## Output Template

```text
## Belief-Ready Audience Analysis

---

### Primary: Belief-Ready

**Who:** [From Module 05 Filter]
**FROM Belief:** "[Limiting belief]"
**Signals:** [How to identify]
**Where:** [Channels]

---

### Secondary: Belief-Curious

**Nurture Path:** Awareness Education Activation

---

### Not For Us

**Who:** [From Filter]
**Why Excluded:** [Rationale]

---

### Statement-to-Stage Mapping

This is CRITICAL it determines which statements reach which audience.

| Belief Stage              | Audience State    | Statements to Use  | Content Types                     |
| ------------------------- | ----------------- | ------------------ | --------------------------------- |
| **Unaware Problem-Aware** | Don't see problem | Statement 1        | Awareness ads, pattern interrupts |
| **Problem-Aware Curious** | Questioning       | Statement 2        | Educational, myth-busting         |
| **Curious Ready**         | Open to truth     | Statement 3        | Core messaging, manifesto         |
| **Ready Converted**       | Need proof        | Statements 4, 5, 6 | Case studies, offers              |
| **Converted Advocate**    | Ready to share    | Statement 7        | Referral, community               |

---

### Audience-Statement Fit Check

| Audience Segment | Primary Statements | Why                                         |
| ---------------- | ------------------ | ------------------------------------------- |
| Belief-Ready     | 3, 4, 5, 6         | Already questioning give truth + proof      |
| Belief-Curious   | 1, 2, 3            | Need problem awareness and belief challenge |
| Not For Us       | None               | Don't target with statements                |
```

---

## Quality Gate

- [ ] Audience matches Module 05 Filter
- [ ] Statement-to-stage mapping complete
- [ ] Belief-Ready know which statements to use first
- [ ] Not For Us explicitly excluded from all statements

---

**If stuck:** If your audience segments all sound like different descriptions of the same person, you haven't split them by belief-readiness. The question isn't "who are they?" — it's "what do they currently believe, and how ready are they to believe something different?" That gap defines the segment.
