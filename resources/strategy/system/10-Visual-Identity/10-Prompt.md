## Visual Strategy translation standard — required

Translate strategy into an experience before translating it into design. The Canonical Strategy must give a founder and competent designer a clear visual problem to solve: **clear enough to picture; open enough to create.** Do not replace derivation, fixed/flexible/unresolved boundaries, evidence discipline, multiple concept routes or human approval.

Render the client-facing Visual Strategy in this order: Executive Summary; creative idea; immediate explanation; one-sentence designer brief; intended experience; Brand derivation; visual characteristics; visual behaviours; creative tensions and anti-territories; creative freedom; and practitioner handoff.

For each material characteristic, state: **Characteristic; Intended feeling; Brand-specific meaning; Think; Not this.** A metaphor or experience may aid imagination but must be labelled as a thinking aid, never a literal theme. Documents, hands, materials, rooms and working marks are possible ways to make human judgement visible, never prescribed imagery.

Visual behaviours describe the job of the identity, not a required device. They may show what leads, what connects, how information states differ, the hierarchy and the next decision. The designer decides how those behaviours become visual.

For Langfell, prevent these predictable errors: `working material` does not mean deliberately rough or documentary-consultancy aesthetics; `one clear beginning` means hierarchy, not uniformly sparse layouts; warmth does not prescribe lifestyle photography; restraint does not mean anonymous minimalism; and delivery surfaces must not become faux-SaaS interface theatre.

Require two or three materially different concept routes. Each must name its proposed organising idea: the visual behaviour or principle that could make the identity recognisable. Routes must differ in organising logic, not merely typography, colour or imagery. The Canonical Strategy does not contain moodboards, references, concepts or technical specification; the later Practitioner Brief may add them.

## Critique Loop

Module 10 produces visual strategy and visual direction statements that will guide design work. After generating the Visual Strategy Statement and key visual briefs, run a **Statement Self-Critique** or route to a human reviewer. No `critique-agent.md` exists; do not invoke a non-existent agent.

**Critique lenses:**
- **Accessibility lens:** Will the visual direction descriptions be understandable to designers and stakeholders? Is visual jargon contextualised? Are accessibility requirements (colour contrast, readability, focus states) included in the Layer 7 artefact?
- **Coherence lens:** Does the visual strategy align with Module 05 brand identity and conviction anchors?

**Flow:**
1. Generate Visual Strategy Statement/brief → Self-critique using the two lenses
2. If it passes → Move to next deliverable
3. If it fails → Revise → Re-critique (up to 3 rounds)
4. Repeat for key visual briefs
5. If deadlock after 3 rounds → Human review event; record reviewer, decision, and rationale

**Principles / Tokens / Implementation separation.** The Layer 7 artefact must distinguish three layers:
- **Principles:** Why a visual choice exists (linked to Module 05 anchors).
- **Tokens:** Named, platform-agnostic values (colours, type scales, spacing scales, radius) that downstream implementations reference.
- **Implementation:** Examples or notes for how tokens are applied in specific media (web, print, motion, packaging), without locking implementation decisions into the token layer.

### Layer 2: Spatial Logic

**Purpose:** Derive a Spatial Logic statement from Module 05 — medium-agnostic, principle-level, not yet numeric.

### System Prompt — Two-Step Translation Process (per FW_16)

Spatial Logic is especially vulnerable to presenting familiar choices as derivation. Focal, Containment and Breathing can sound specific to a brand even when they come from a glance at sector conventions: *one focal point, tight grid, generous whitespace*. Without verbatim Module 05 anchors, Layer 2 reproduces those conventions and passes them into every downstream layer.

This deliverable runs as a strict two-step process. **Step 1 produces nothing but verbatim upstream quotations.** Step 2 produces the Spatial Logic property derived from those quotations.

**Step 1 — Quote Upstream Anchors Verbatim.** For each of the three properties, locate the specific Module 05 artefact(s) named in the Translation Discipline table above (Layer 2 row). Copy them verbatim as the first content block under each property heading. Do not paraphrase, summarise or substitute wording that captures their spirit. If a required upstream artefact is missing, halt this layer and surface the missing input — do not proceed to Step 2 with a paraphrased substitute and do not reach for a default visual posture to fill the gap.

**Step 2 — Translate Each Quote into a Spatial Property Statement.** With the verbatim quotes in place, write the Focal / Containment / Breathing statement *derived from* the quoted source. The statement is a spatial translation of the upstream conviction, not a fresh visual preference. Each statement must contain at least one phrase that visibly traces back to a word or concept in the quoted source.

**No-select-from-menu guardrail:** if the derived statement matches the sector convention (e.g., financial services → "tight containment, generous breathing"), you must check whether that match is *coincidence of conviction* or *capitulation to convention*. Test: substitute a competitor's Module 05 into the same quotation slots. If the Spatial Logic statement comes out the same, the prompt is selecting, not deriving. Push the source back in and re-derive against the *distinguishing* anchor words in this brand's Personality / Values / Voice / Filter / Brand Strategy.

**Test (per FW_16):** if any Spatial property statement could plausibly be written by someone who has not read this brand's Module 05 Handoff Pack, the layer slipped into discovery or selection mode. Push the source quotation back in and re-derive.

## If Stuck

If derivation feels arbitrary or the output feels generic, the most likely cause is a skipped layer:

| Symptom | Most likely skipped layer |
| --- | --- |
| Output feels generic | Layer 3 (Resonance Position) under-derived — return to Module 05 |
| Direction feels abstract or designers disagree on what it means | Layer 4 (Design Behaviour Translation) is incomplete — return and add behaviours, boundaries or verification |
| Output doesn't fit the brand's sector | Layer 5 (Context Narrowing) under-applied |
| Builder can't react to variation strategies | Exploration Layer strategies are too similar — re-author with sharper differentiation |
| Output artefact feels under-specified for the use case | Wrong operating model declared at Layer 6 — re-evaluate |

The framework is procedurally specifiable at every layer. If derivation feels arbitrary, derivation is incomplete.
