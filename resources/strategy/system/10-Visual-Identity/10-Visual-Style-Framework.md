# Module 10: Visual Style Framework

**Langfell™**
_Layered Derivation System for Visual Identity_

---

## Purpose

The Visual Style Framework derives a brand's visual identity through seven layers, from conviction to execution in each medium. **It does not present a menu of named styles to select from.**

**Core principle:** Derivation, not selection. Every visual decision traces through the layers, each putting the previous one into practice. The 12 named styles later in this document provide **reference vocabulary**: labels used to communicate the result, never inputs to the derivation.

---

## The Layered Derivation Chain

Visual identity is derived through seven layers, each narrowing the previous:

```text
LAYER 1: CONVICTION
   (inherited from Module 05)
        |
        v
LAYER 2: SPATIAL LOGIC
   Focal point · Containment · Breathing
        |
        v
LAYER 3: RESONANCE POSITION
   Six binary pairs (property axes)
        |
        v
LAYER 4: DESIGN BEHAVIOUR TRANSLATION
   Translation engine — commitments to observable behaviour
        |
        v
LAYER 5: CONTEXT NARROWING
   Sector × Medium × Audience
        |
        v
LAYER 6: OPERATING MODEL
   Expressive (principles) vs Controlled (locked specs)
        |
        v
LAYER 7: OUTPUT ARTEFACTS
   Brand Style Guide / Operating Constitution / Style System
   + medium-specific derivatives (DESIGN.md, brand kit, etc.)
```

Each layer is necessary. Skipping any layer produces selection masquerading as derivation.

---

## Layer 1: Conviction (Module 05 Inheritance)

Layer 1 is **inherited, not derived**. It comes from Module 05 — the brand's Core Belief, Brand Personality, Values, Voice, Filter, and Positioning. Nothing in Module 10 modifies these. Everything in Module 10 derives from them.

**What Layer 1 provides:**

- The brand's belief — the conviction Module 10 makes visible
- The brand's personality — driving Layer 3's resonance position
- The brand's values — informing Layer 2's spatial logic
- The brand's voice — driving Layer 3's restraint axis
- The brand's filter — informing Layer 5's audience constraint

**Anchoring check:** Layer 1 must be genuinely anchored, not aspirational (see Gate 0 in `10-README.md`). A visual identity derived from aspirational Module 05 propagates the additive default at the most public layer of the business — the maximum-damage pattern named in `10-Philosophy.md`.

---

## Layer 2: Spatial Logic

Spatial Logic is the first visual translation of conviction. It defines **layout behaviour**, not specific values, through three properties:

### The Dot — Focal Logic

How the eye lands. How many focal points per composition. Where they sit relative to the frame. Whether they're anchored centrally, off-centre, or distributed.

**Derived from:** Module 05 Personality (assertive → strong central focal; quiet → off-centre or distributed) and Values (clarity → single focal; abundance → multiple focals).

### The Circle — Containment

What's inside the frame. Whether the brand uses tight containment (everything pulled toward the centre, controlled edges) or loose containment (elements permitted to break the grid, flow off the page).

**Derived from:** Module 05 Filter (tight Filter → tight containment; permissive Filter → loose containment) and Brand Strategy (premium → tight; democratic → loose).

### The Space Between — Breathing

The ratio between content and emptiness. Whether the brand operates at high information density or breathes generously. How much negative space functions as a design element in its own right.

**Derived from:** Module 05 Voice (restrained → generous breathing; expressive → dense) and Personality (quiet authority → generous; bold → dense).

**Output of Layer 2:** A short Spatial Logic statement, e.g., _"One focal point per composition. Tight containment. Generous breathing."_ This statement is medium-agnostic — it governs digital, print, packaging, and motion equally.

---

## Layer 3: Resonance Position

Layer 3 expresses the brand's emotional and perceptual posture through six binary pairs. The pairs derive from how audiences _perceive_ visual identities, rather than the techniques designers use to _produce_ them. They describe properties, not aesthetic categories.

### The Six Pairs

| Pair | Word A | Word B | What This Distinguishes |
| ---- | ------ | ------ | ----------------------- |
| 1 | Warm | Cool | Human/approachable vs precise/institutional |
| 2 | Spacious | Dense | Breathing room vs full/rich |
| 3 | Calm | Energetic | Still and quiet vs moving and loud |
| 4 | Restrained | Expressive | Held back vs bold statement |
| 5 | Clean | Raw | Polished and considered vs unpolished and honest |
| 6 | Focused | Layered | Single focal point vs multiple elements |

**Each pair marks a territory, not a point.** A brand sitting on the _Warm_ side isn't committing to any single shade of warmth — it's declaring direction. The Design Behaviour Translation at Layer 4 turns the direction into observable, testable practice without prematurely selecting a style.

### How Resonance Position Derives from Module 05

| Module 05 Output | Primary Resonance Axes |
| ---------------- | ---------------------- |
| Personality | Warm/Cool, Restrained/Expressive |
| Values | Spacious/Dense, Clean/Raw |
| Voice | Calm/Energetic, Restrained/Expressive |
| Filter | Focused/Layered |
| Brand Strategy | All axes — final calibration |

**Output of Layer 3:** A six-axis resonance signature, e.g., _"Warm + Spacious + Calm + Restrained + Clean + Focused."_

### Why Pairs, Not Single Words

Each pair forces a directional commitment. _"This brand is warm"_ is a single direction; _"warm or cool — choose"_ is a forcing function. The binary commitment is what makes downstream interpretation possible. Spectrum language ("somewhat warm, kind of cool") cannot produce specifiable output.

The pairs are also the bridge to the parallel Langfell Visual Contract product, which uses the same six pairs as a free communication tool for non-designers briefing designers. Module 10 derives the position from conviction; the Visual Contract has the user choose by feel. Both produce the same six-axis resonance signature; the framework's contribution is the upstream derivation chain that anchors the position in conviction rather than preference.

## Layer 4: Design Behaviour Translation

Layer 4 translates each Layer 3 commitment into observable design behaviour. It explains what a practitioner should compose, prioritise, reduce, relate or test before choosing a style asset. It does not select typefaces, colours, grids, spacing values or final imagery.

For every commitment, record:

| Field | Requirement |
| --- | --- |
| Intent | Why this quality serves the strategy. |
| Behaviours | Observable choices in hierarchy, spacing, type, colour, imagery, interaction or material. |
| Verification | A context-appropriate inspection method. |
| Failure signals | Undershoot, overshoot or structural drift. |
| Freedom retained | Decisions the practitioner still owns. |

### Core behaviour rules

- **Warm:** introduce human presence, material or typographic character where it supports the message; do not equate warmth with warm colours, rounded corners or smiling people.
- **Spacious:** separate changes of thought, control density and allow consequential material room to land; do not prescribe a universal whitespace percentage.
- **Calm:** establish one clear entry point, limit competing emphasis and use motion only to clarify sequence or consequence.
- **Restrained:** make a few decisive moves, use accents purposefully and gain recognition through organising logic rather than ornament.
- **Clean:** make alignment, grouping, spacing and information states precise; clean must not mean sterile, generic or frictionless.
- **Focused:** give each principal surface one identifiable first-read element and visibly subordinate supporting material unless simultaneous attention is necessary and explained.

Typography must support sustained reading, decisive but non-theatrical hierarchy and distinct recommendation, evidence, qualification and metadata states. Colour must have a named job: recognition, focal direction, meaningful relationship or non-exclusive information state. Imagery must establish human presence, context, evidence, conceptual clarity, an intentional pause or recognition. Styling must not rescue an unresolved hierarchy, sequence or relationship.

### Conditional specification

Numeric values, token ranges and technical parameters may be created only after a concept route is selected and the operating model, medium, accessibility requirements and production fidelity authorise specification. They are project-specific implementation choices, not a universal meaning of a Resonance position.

**Output of Layer 4:** a commitment-by-commitment Design Behaviour Translation and selected design tests. Layer 5 narrows these behaviours for the actual sector, medium, audience and constraints.

## Layer 5: Context Narrowing

Layer 5 adapts the Layer 4 behaviours to _this brand's_ context. Examine the three narrowing inputs **independently**. A brand can be unusual on one and conventional on another; the record must show which condition changes each behaviour.

### Three Narrowing Sub-Inputs (Interrogated Separately)

**Sub-Input 5a — Sector context.** Trust-sensitive sectors may require more explicit evidence states, steadier hierarchy or additional accessibility constraints. _Ask: what does this brand's sector demand, and where does this brand intend to honour or deviate from that convention?_

**Sub-Input 5b — Medium.** Mobile, large-format print, packaging and motion each change how a behaviour can be expressed. _Ask: which media is this identity primarily expressed in, and what does each medium require?_

**Sub-Input 5c — Audience reading pattern.** Executive scanners may need a faster path into a Spacious direction; long-form readers may need more room for sustained reading. _Ask: how does this audience actually consume content, and what density and pace does that demand?_

Record the reasoning for each sub-input separately so a reviewer can trace each change in behaviour to its context.

### External Constraints (Permitted Non-Derived Inputs)

Layer 5 also accepts external constraints the brand must honour. Record these separately from inputs derived from conviction:

- **Accessibility floors** — AAA contrast ratios, minimum touch targets, font-size minimums. Non-negotiable regardless of resonance position.
- **Regulatory constraints** — sector-mandated colour/labelling rules (pharmaceutical, financial disclosure, food labelling, safety).
- **Platform constraints** — channel-specific aspect ratios, character limits, file-size ceilings, codec requirements.

These bound the authorised behaviour; they do not derive it. If an accessibility or legal requirement conflicts with an intended behaviour, the requirement wins and the record names the adjustment.

### The Narrowing Principle

```text
Contextual behaviour = Layer 4 behaviour, adapted by Sector (5a), Medium (5b), and Audience (5c) independently,
                     then bounded by any applicable External Constraints
```

Use judgement and record the source of each adaptation. Specific values belong only in an authorised later specification.

**Output of Layer 5:** contextual behaviour guidance for priority surfaces, accompanied by per-sub-input reasoning (5a, 5b, 5c) and an explicit External Constraints note.

## Layer 6: Operating Model

At Layer 6, the brand must explicitly choose an Operating Model. This choice determines what Layer 7 produces.

### Expressive vs Controlled

| | Expressive | Controlled |
| --- | --- | --- |
| Examples | Teenage Engineering, Aesop, indie craft brands, founder-driven cult brands | Banks, law firms, insurance, healthcare, regulated SaaS, enterprise platforms |
| What stays constant | The animating principle — resonance, spatial logic, conviction | The specific specifications — typography, colour values, components, layout |
| What varies | Expression varies project-to-project, surface-to-surface | Expression is locked across touchpoints |
| Trust mechanism | Range itself signals authenticity ("they're alive, not on a template") | Consistency itself signals reliability ("they're solid, the same every time") |
| Output document | **Operating Constitution** | **Style System** |
| Decisions get made by | Reference to principles + fresh interpretation | Reference to fixed specs (lookup) |

### How to Decide

The choice is driven by four inputs:

- **Sector trust requirements** — regulated/trust-sensitive sectors → Controlled; creative sectors → either
- **Audience trust sensitivity** — high → Controlled; high creative-credibility → Expressive
- **Conviction posture** — _"we want to be recognisable above all"_ → Controlled; _"we want to feel alive and surprising"_ → Expressive
- **Distribution model** — mass-scale consumer brand → Controlled; founder-driven cult brand → Expressive

These usually converge. If they don't, sector trust requirements dominate.

**Output of Layer 6:** A single declaration — _"This brand operates Expressive"_ or _"This brand operates Controlled."_ Layer 7's output structure depends entirely on this choice.

### Hybrid Operation in Practice

The binary Controlled / Expressive declaration is a real choice the framework requires. It doesn't deny that real brands sometimes operate primarily one way with deliberate variance in the other — Aesop is mostly Controlled but ran Expressive editorial work; Patagonia is mostly Expressive but their product photography is tightly Controlled.

**The brand must declare one Primary Operating Mode at Layer 6.** If specific surfaces need the other mode, define them as **Secondary Mode Zones**. These are named exceptions with rules; the primary lock still holds.

Rules for Secondary Mode Zones:

1. **Named surfaces only.** A Secondary Mode Zone applies to specific touchpoints declared in advance — _"editorial content,"_ _"founder communications,"_ _"product photography,"_ _"seasonal campaigns."_ Not _"sometimes."_
2. **Bounded by the Visual Signature Label.** The Signature Label holds across both modes. A Controlled brand with an Expressive editorial zone still expresses the same Signature in both — the difference is whether values are locked or interpreted, not whether the conviction holds.
3. **The Primary Mode's Layer 7 artefact governs the boundary.** A Style System (Controlled-primary) with an Expressive editorial zone names what is locked even within the Expressive surface — typography family, palette frame, photographic conviction — and what is permitted to vary.
4. **Un-scoped drift between modes is the failure case.** A brand that's _sometimes_ Controlled and _sometimes_ Expressive without named zones is operating without a Layer 6 lock at all — the broken state the binary declaration exists to prevent.

The default is a brand with no Secondary Mode Zones. Hybrid operation is permitted within defined boundaries and rules; it does not remove the need for a Layer 6 decision.

**When Hybrid is the honest call:** if the four decision inputs above don't converge — for example, a creative-credibility audience (pulling Expressive) inside a trust-sensitive sector (pulling Controlled) — the answer is usually Controlled-primary with named Expressive Zones for the surfaces where creative credibility is the dominant trust mechanism. The reverse (Expressive-primary with Controlled Zones) is rarer but legitimate for founder-driven brands with regulated touchpoints (legal disclosures, packaging compliance, certifications).

### Worked Operating Model Cases

Use these as decision examples, not templates. The point is to show how the four inputs force the declaration.

| Case | Sector Trust | Audience Trust | Conviction Posture | Distribution | Declaration |
| --- | --- | --- | --- | --- | --- |
| **Payroll compliance bureau** | High: payroll, pensions, HMRC exposure | High: owners need reliability more than novelty | "We remove risk quietly" | Repeatable B2B delivery | **Controlled.** Locked typography, colour, layout, and document templates carry the trust signal. Expressive range would read as instability. |
| **Founder-led furniture studio** | Low regulation; craft credibility matters | Buyers read material honesty and maker taste | "Furniture should show the hand that made it" | Small-batch, founder-led, portfolio-led sales | **Expressive.** The principle stays constant, but each collection can carry a slightly different expression. Locking every surface would flatten the maker signal. |
| **B2B workflow consultancy** | Moderate: operational advice must feel serious | Founders want truth without theatricality | "The workflow lies before the team fails" | Website, diagnostic reports, workshops | **Controlled.** The diagnostic posture depends on repeatable evidence presentation. Diagrams, annotations, and report layouts need a locked system. |
| **Design-led fertility clinic** | High: healthcare trust, consent, patient safety | Also high creative sensitivity: patients want warmth, not institutionality | "Clinical care can feel human without becoming vague" | Clinic environment, website, patient documents, founder essays | **Controlled-primary with Expressive Zones.** Clinical journey, consent, pricing, and treatment pages stay Controlled. Founder essays, waiting-room editorial, and community events become named Expressive Zones bounded by the same Visual Signature Label. |

The Hybrid case retains one Primary Operating Mode and names the exceptions: the surfaces allowed to interpret the conviction rather than repeat the specification.

## Layer 7: Output Artefacts

Layer 7 produces the framework's deliverables. The artefact structure depends on the Layer 6 declaration. Every Layer 7 artefact must separate **Principles**, **Tokens**, and **Implementation**, and include **accessibility** and **RouteAuthorization** notes.

### Required at the Top of Every Layer 7 Artefact: The Visual Signature Label

Before the specification details (Controlled) or principles (Expressive), every Layer 7 artefact opens with a **Visual Signature Label** — a short proprietary descriptor (typically 2–4 words) that names the visual position the chain derived. Examples: _Restrained Confidence_, _Quiet Architecture_, _Warm Precision_, _Disciplined Play_.

The Signature Label is **owned by the brand**, distinct from the 12 named styles. It derives from the brand's Layer 1 conviction, Layer 3 resonance position and Layer 5 context. Builders, clients and downstream collaborators use it to discuss the visual identity in the brand's own terms, without importing a named style's cultural baggage.

A builder who has paid for a brand process needs a position they can **name** and explain. _"Our visual signature is Restrained Confidence — here's what that means and what it doesn't"_ gives them that, even when no named style fits.

Authoring rules:

- 2–4 words, no longer
- Drawn from the brand's own conviction vocabulary (Module 01 Natural Language Bank) where possible
- Names the **position**, not the **mood** ("Restrained Confidence" not "Calm and Trustworthy")
- Cannot be the same as one of the 12 named styles, and must not be a synonym ("Quiet Minimalism" is just Minimalism)
- Must be traceable: the artefact lists which Layer 3 axis positions and which Layer 1 conviction inputs produced it

### If Controlled → Style System

A locked specification artefact containing:

- **Visual Signature Label** (required — see above)
- **Principles section** — why each visual choice exists, linked to M05 anchors
- **Tokens** — named, platform-agnostic values (colour, type scale, spacing, radius, motion)
- **Implementation examples** — web, print, motion, packaging references to tokens without redefining them
- **Brand Style Guide** (medium-agnostic art direction — the source of truth)
- **DESIGN.md** (digital design system with locked values, consuming the tokens)
- **Print spec sheet** (CMYK, paper stock, finish, structural rules)
- **Brand kit** (Canva or similar, populated with locked values)
- **Design tokens** (JSON file consumable by build systems)
- **Image-prompt modifier library** (locked phrase set for AI image generation)
- **Logo and lockup specifications**
- **Component library** (buttons, cards, forms — locked styling, referencing tokens)
- **Accessibility notes** — minimum contrast, readable type sizes, focus states, reduced-motion preference
- **RouteAuthorization field** — copied from M04

Every value is locked, and every touchpoint references the same specs to keep the brand's expression consistent across contexts.

### If Expressive → Operating Constitution

A principles artefact containing:

- **Visual Signature Label** (required — see above)
- **Principles section** — why each visual choice exists, linked to M05 anchors
- **Tokens** — named, platform-agnostic values where the brand does lock a value (e.g. primary typeface, signature colour), with free axes left as ranges
- **Implementation examples** — web, print, motion, packaging references to tokens without redefining them
- **Conviction-anchored visual character statement** (philosophical centre)
- **Spatial logic principles** (focal/containment/breathing — operationalised but not numeric)
- **Resonance position** with _examples_ of acceptable expression range across multiple touchpoints
- **Decision questions** for new touchpoints (_"what does our conviction demand here?"_)
- **Example renderings** showing the range — three to five distinct expressions, all coherent
- **Image-prompt modifier library** (less restrictive than Controlled version — emphasises the conviction, leaves room for context)
- **Boundary statements** (what the brand never does)
- **Accessibility notes** — minimum contrast, readable type sizes, focus states, reduced-motion preference
- **RouteAuthorization field** — copied from M04

For each new touchpoint, ask: _"Given our principles, how should this particular expression go?"_ Expression varies across contexts; shared principles keep it coherent.

### Common Layer 7 Outputs (Both Operating Models)

Regardless of operating model, every Layer 7 artefact includes:

- **Image-prompt modifier library** — brand-specific phrases for AI image generation, derived from Layer 4 behaviours
- **Photography direction** (mood, subject, treatment, what to avoid)
- **Application examples across mediums**
- **Do/Don't usage rules**
- **Source document linkage** — every downstream artefact (DESIGN.md, brand kit, etc.) cites the Layer 7 source
- **Principles / Tokens / Implementation separation** — principles explain why, tokens are named values, implementation examples reference tokens
- **Accessibility notes** — contrast, readable type sizes, focus states, reduced-motion preference
- **RouteAuthorization field** — copied from M04

### Handoff to the Design Industry

The Layer 7 artefact (Style System or Operating Constitution) is the framework's canonical source. Designers, agencies, and in-house design teams don't work from artefacts with these names — they work from brand guidelines, design systems, design tokens, Figma libraries, and creative briefs. Layer 7 sits upstream of all of those; it doesn't replace any of them.

The practitioner uses Layer 7 to brief the conventional deliverable, which the designer then produces. Both documents exist and serve different audiences.

| Layer 7 Source (Langfell-internal) | Conventional Deliverable (industry-facing) | Who Builds It |
| --- | --- | --- |
| Style System (Controlled) | **Brand Guidelines** document — logo, typography, colour, voice, usage rules | Designer or agency, from the Style System brief |
| Style System (Controlled) | **Design System** — Figma library, component specs, design tokens (JSON), CSS variables | Designer / design engineer, from the Style System's locked numeric values |
| Operating Constitution (Expressive) | **Creative Brief** + **Principles Doc** — articulates the conviction and the range, with three to five reference renderings | Practitioner or strategist, with designer review |
| Operating Constitution (Expressive) | **Reference Library** — curated examples of acceptable expression, with annotations on what makes each one coherent | Designer or art director, with practitioner approval |
| Either | **Image-prompt modifier library** | Practitioner — already produced as part of Layer 7 |
| Either | **Photography brief** for shoots | Practitioner or art director, from Layer 7 photography direction |

In most engagements, the practitioner **adapts Layer 7 into a brief for the designer**. It serves the same purpose as a creative director's internal strategy document: the source for the production brief sent to the studio.

What the designer needs to know about Layer 7:

- It is the canonical source — every conventional deliverable derives from it
- It contains the Visual Signature Label, which the designer should treat as the brand's owned position (not as one of the 12 named styles)
- The approved behaviours, contextual constraints and later authorised specifications are non-negotiable downstream — the designer's role is to express them across mediums, not to relitigate them
- Changes to the visual identity require Layer 7 to be amended first, not the designer's deliverable

What the practitioner needs to deliver to a designer:

- The Visual Signature Label and a short paragraph on what it means
- The Layer 7 locked values (Controlled) or principles + range examples (Expressive)
- The image-prompt modifier library
- The photography direction
- The Do/Don't usage rules
- The application examples across mediums
- A conventional creative brief that translates the above into the deliverable's format

A designer or agency builds the brand guidelines from the practitioner's brief. Layer 7 supplies the source from which those deliverables derive.

## Chain Re-Entry

Real visual identity work iterates. The rule is simple: identify the first broken layer, then re-run from that layer forward. Do not patch the visible output while leaving the broken layer untouched.

### How to Find the Broken Layer

| Symptom in live use | First layer to inspect | Typical cause |
| --- | --- | --- |
| The identity feels polished but false | Layer 1 / Module 05 | Brand identity was aspirational or has changed |
| People feel _something_, but not the intended conviction | Layer 3 | Resonance Position expressed the wrong emotional posture |
| Values are right in principle but inconsistent in execution | Layer 4 | Commitments were not translated into usable behaviours and verification |
| Website works but social, print, or product surfaces break | Layer 5 | Sector/medium/audience narrowing was incomplete |
| Designers keep asking whether to follow rules or interpret principles | Layer 6 | Operating Model was implicit or Secondary Mode Zones were not scoped |
| One new campaign sits outside the identity but the core system still works | Layer 7 | Layer 7 needs an amendment, not a full rebrand |

### Cost of Change

| First broken layer | Cost level | What changes |
| --- | --- | --- |
| Layer 1 / Module 05 | Rebrand-level | Re-lock Module 05 and re-run Module 10 from the start. Public explanation may be needed. |
| Layer 3 | High | Rebuild resonance, behaviour translation, operating model, and Layer 7. Existing visual assets may need replacement. |
| Layer 4 | Medium | Rework behaviours and downstream briefs. Public identity may stay recognisable, but execution rules change. |
| Layer 5 | Low to medium | Recalibrate affected media or audience contexts. Usually a touchpoint correction. |
| Layer 6 | Medium | Re-issue the Layer 7 artefact as Style System or Operating Constitution, and brief downstream teams again. |
| Layer 7 | Low | Amend the source artefact and regenerate affected 10B outputs. No public change is required unless shipped assets are already live. |

### Communication Rule

Name the change at the same depth as the break. Do not tell a team _"we're refreshing the visuals"_ if the truth is _"our Module 05 anchor was aspirational."_ Do not tell the market _"we've rebranded"_ if the truth is only _"we tightened our social templates."_ Accurate naming prevents defensive explanation and keeps the system honest.

Iteration is expected. Skipping is not.

## The Exploration Layer

Between Layer 6 and Layer 7, the framework supports stylescape exploration through **three variation strategies** — different routes through the framework's authorised free space, all coherent with the conviction.

### Why Three Strategies, Not Three Options

Traditional design agencies present three or four design options to a client. The problem is that those options are usually three near-identical interpretations of one direction (different colour swaps of the same essential solution) — or three completely different directions that share no common conviction. Neither serves the client well.

The framework's variation strategies are different. They:

- All satisfy the **locked axes** (the conviction is honoured across all three)
- Take **meaningfully different routes** through the **free axes** (the choice is real)
- Each produces a **standalone, complete** Layer 7 specification

### Authoring the Three Strategies

For each brand, the framework identifies which axes from Layer 3 are most expressive of the conviction (locked) and which axes have legitimate range (free). The three strategies then take different positions on the free axes:

**Example for a brand with locked Warm + Spacious + Restrained + Focused:**

- **Strategy A — Calm route:** Emphasises softness, organic curves, generous padding, asymmetric breathing. Spaciousness expressed as meditative breathing room.
- **Strategy B — Editorial route:** Emphasises sharp typography contrast, dramatic hierarchy, restrained palette with one bold accent. Spaciousness expressed through whitespace as design element.
- **Strategy C — Material route:** Emphasises tactile texture, warm neutrals, near-flat composition, single anchor element per frame. Spaciousness expressed through restraint of competing elements.

All three remain _Warm + Spacious + Restrained + Focused_, consistent with the conviction. They differ in how they resolve the free axes.

### Builder/Client Reaction

The builder reviews all three and chooses a route — _"yes, B is the one, that considered authority is what we want."_ That route becomes the basis for Layer 7's locked output. Document the two rejected routes so future builders and reviewers can see what was considered and ruled out.

## The 12 Named Styles — Reference Vocabulary Only

The 12 named styles below function as **reference vocabulary** — labels for communication, not destinations for derivation.

After Layer 5 produces context-narrowed values, the resulting specification _can_ be labelled by reference to a named style for ease of communication:

> _"This brand's specification sits closest to the Editorial cluster, with restraint pulled toward Minimalism."_

This labelling is post-hoc. It does not drive the specification. The 12 styles are vocabulary, not menu.

### Why the Named Styles Are Not Derivation Inputs

Named styles import cultural and aesthetic baggage that may not match the brand's actual conviction. _Minimalism_ doesn't just mean "restrained" — it imports an entire aesthetic movement with specific cultural references, audience associations, and historical context. _Vaporwave_ doesn't just mean "surreal" — it's a youth-culture-coded stance with internet-native semantics. _Brutalism_ doesn't just mean "raw" — it carries anti-corporate, anti-aesthetic political content.

Deriving _toward_ a named style smuggles selection back into the framework, no matter how disciplined the mapping rule appears. The framework derives at the level of **property axes (Layer 3)** and **observable behaviours (Layer 4)**, not at the level of named styles. The styles describe historical aesthetic territories. The brand's specific position may overlap with one or several territories but is never _defined_ by them.

This is also why the framework permits "no named style" as a valid outcome. If the derivation produces a specification that doesn't map cleanly onto any of the 12, that's a sign the brand has a genuinely distinctive position — not a sign that something is wrong. The framework prefers honest derivation over forced labelling.

---

### 1. Minimalism

**One-Line Description:** Reduction as philosophy — every element earns its place through essential purpose.

**Core Feel:** Clean, focused, essential, restrained, confident

**Typical Industries:** Luxury goods and services, fintech and banking, tech/SaaS, wellness and health, architecture and interior design, premium consumer goods

**Typical Personalities:** Confident, Refined, Intentional, Premium, Sophisticated

**Why This Match:** Minimalism signals confidence through restraint. Brands that don't need to shout to be noticed. Premium positioning without decoration.

**Typical Fonts:** Sans-serif (Helvetica Neue, Inter, SF Pro, Suisse Int'l), Serif sparingly (Canela, GT Sectra, Freight Display) — clean letterforms, generous tracking, considered weights

**Typical Colours:** Neutral-dominant palettes (black, white, greys); single accent colour, often muted; low saturation; high contrast

**Typical Graphic Elements:** Generous whitespace, strong grid systems, subtle photography, flat iconography, minimal texture

---

### 2. Maximalism

**One-Line Description:** Abundance as expression — more is more, layered richness communicates energy.

**Core Feel:** Bold, layered, abundant, energetic, expressive

**Typical Industries:** Fashion and beauty, entertainment and media, gaming, music and events, lifestyle brands, creative agencies

**Typical Personalities:** Creative, Bold, Expressive, Playful, Provocative

**Why This Match:** Maximalism signals creative confidence and rejection of conformity. Brands that celebrate excess and self-expression.

**Typical Fonts:** Mixed typefaces (display + body), decorative and experimental fonts, variable fonts with extreme weights — layered, overlapping, dynamic sizing

**Typical Colours:** High saturation, multiple accent colours, bold combinations, gradients and colour transitions, pattern overlays

**Typical Graphic Elements:** Layered compositions, mixed media (photo + illustration + type), texture-rich surfaces, dense layouts, animated elements

---

### 3. Brutalism

**One-Line Description:** Raw honesty as aesthetic — deliberate roughness signals authenticity over polish.

**Core Feel:** Raw, unpolished, defiant, authentic, direct

**Typical Industries:** Art and culture, indie/independent brands, streetwear and urban fashion, creative agencies, music labels, activist organisations

**Typical Personalities:** Authentic, Rebellious, Honest, Anti-establishment, Unconventional

**Why This Match:** Brutalism signals rejection of corporate polish. Brands that value substance over presentation, authenticity over perfection.

**Typical Fonts:** System fonts (deliberately), monospace, heavy sans-serif — stark, often default, intentionally "undesigned"

**Typical Colours:** High contrast (black/white dominant), neon accents (yellow, green, red), minimal palette, harsh combinations

**Typical Graphic Elements:** Exposed grid/structure, raw HTML aesthetic, thick borders, intentional "broken" layouts, no rounded corners

### 4. Art Deco

**One-Line Description:** Geometric glamour — luxurious symmetry evoking timeless elegance.

**Core Feel:** Glamorous, geometric, luxurious, sophisticated, timeless

**Typical Industries:** Luxury hospitality, high-end real estate, premium spirits and beverages, jewellery, fashion (heritage brands), entertainment venues

**Typical Personalities:** Prestigious, Timeless, Sophisticated, Glamorous, Refined

**Why This Match:** Art Deco signals established prestige and enduring quality. Brands positioning as timeless rather than trendy.

**Typical Fonts:** Geometric sans-serifs (Futura, Avant Garde, Brandon Grotesque), Art Deco display (Broadway, Parisian, Poiret One) — geometric forms, balanced proportions, elegant caps

**Typical Colours:** Gold, brass, champagne; deep jewel tones (emerald, sapphire, ruby); black and cream; metallic accents

**Typical Graphic Elements:** Geometric patterns (chevrons, fans, sunbursts), symmetrical layouts, decorative borders and frames, line illustrations, gold foil effects

---

### 5. Retro/Vintage

**One-Line Description:** Era-specific nostalgia — authentic connection to a particular time period.

**Core Feel:** Nostalgic, era-specific, warm, authentic, heritage

**Typical Industries:** FMCG (especially food and beverage), fashion (heritage or revival), craft brands (breweries, distilleries), barbershops and grooming, automotive (classic), entertainment (themed)

**Typical Personalities:** Heritage, Authentic, Nostalgic, Warm, Trustworthy

**Why This Match:** Retro signals established heritage and timeless quality. Brands using nostalgia to build trust or distinguish themselves from modern competitors.

**Typical Fonts:** Era-specific typography (50s, 60s, 70s, 80s), script and hand-lettered styles, slab serifs and Americana styles — period-appropriate, often custom or hand-drawn feel

**Typical Colours:** Era-specific palettes — 50s pastels (turquoise, coral), 60s (orange, avocado, brown), 70s (earth tones, mustard, rust), 80s (neon, hot pink, electric blue)

**Typical Graphic Elements:** Era-appropriate illustration styles, halftone patterns, distressed textures, badge and emblem designs, retro photography treatments

---

### 6. Editorial

**One-Line Description:** Dramatic hierarchy — magazine-quality layouts that command attention through typography.

**Core Feel:** Dramatic, hierarchical, story-driven, authoritative, sophisticated

**Typical Industries:** Publishing and media, corporate (premium), professional services, fashion (high-end), luxury goods, cultural institutions

**Typical Personalities:** Authoritative, Sophisticated, Intelligent, Premium, Story-driven

**Why This Match:** Editorial signals intellectual authority and content quality. Brands that lead through ideas and perspective.

**Typical Fonts:** High-contrast serifs (Didot, Bodoni, Miller), clean sans for body (Neue Haas, Builders Grotesk) — dramatic size contrast, refined pairings, bold headlines

**Typical Colours:** Sophisticated neutrals, single accent colour, high contrast black/white, subtle tonal variation

**Typical Graphic Elements:** Magazine-style layouts, pull quotes and large typography, strong grid but with intentional breaks, high-quality photography, generous margins

---

### 7. Neumorphism

**One-Line Description:** Soft dimension — subtle shadows creating gentle, approachable depth.

**Core Feel:** Soft, subtle, dimensional, approachable, calm

**Typical Industries:** Wellness and health apps, fintech (consumer-focused), SaaS products, smart home/IoT, meditation and mindfulness

**Typical Personalities:** Approachable, Calm, Modern, Gentle, Sophisticated

**Why This Match:** Neumorphism signals gentle innovation and approachability. Brands that want to feel modern without being cold.

**Typical Fonts:** Rounded sans-serifs (Circular, Sofia Pro, Nunito), clean geometric (Poppins, Outfit) — friendly, balanced, readable

**Typical Colours:** Soft, muted backgrounds; low contrast; monochromatic schemes; subtle gradients; light mode dominant

**Typical Graphic Elements:** Soft shadows (inner and outer), rounded corners, subtle depth, minimal line work, soft iconography

---

### 8. Glassmorphism

**One-Line Description:** Frosted transparency — ethereal depth through layered translucency.

**Core Feel:** Transparent, frosted, ethereal, futuristic, premium

**Typical Industries:** Tech products, fintech dashboards, creative tools, AR/VR platforms, music streaming, design software

**Typical Personalities:** Cutting-edge, Premium, Futuristic, Innovative, Sophisticated

**Why This Match:** Glassmorphism signals technological sophistication and forward-thinking innovation. Brands at the cutting edge.

**Typical Fonts:** Clean sans-serifs (SF Pro, Inter, Manrope), variable fonts with optical sizing — precise, modern, highly readable on complex backgrounds

**Typical Colours:** Translucent whites and greys, vibrant accent colours (visible through glass), gradient backgrounds, dark mode friendly

**Typical Graphic Elements:** Frosted glass effect (backdrop-blur), layered cards, subtle borders, vibrant gradients behind glass, glowing accents

---

### 9. Flat Design

**One-Line Description:** Bold simplicity — two-dimensional clarity prioritising function and legibility.

**Core Feel:** Bold, two-dimensional, efficient, clear, accessible

**Typical Industries:** Tech and software, mobile apps, e-commerce, startups, educational platforms, government/public services

**Typical Personalities:** Modern, Clear, Accessible, Efficient, Friendly

**Why This Match:** Flat design signals clarity and efficiency. Brands that prioritise usability and accessibility over decoration.

**Typical Fonts:** Geometric sans-serifs (Roboto, Open Sans, Lato), system fonts (for performance) — highly readable, consistent, scalable

**Typical Colours:** Bold, flat colours; no gradients (or very subtle); high-saturation palettes; strong contrast for accessibility

**Typical Graphic Elements:** Flat illustration, simple iconography, no shadows or depth, bold shapes, clean grid systems

### 10. Skeuomorphism

**One-Line Description:** Realistic familiarity — digital elements that reference physical objects.

**Core Feel:** Realistic, textured, familiar, intuitive, tactile

**Typical Industries:** Financial software (traditional), creative applications, wearables and dashboards, games (non-cartoon), productivity tools, navigation/mapping

**Typical Personalities:** Intuitive, Familiar, Tactile, Premium, Detailed

**Why This Match:** Skeuomorphism signals intuitive experience and premium quality. Brands that want to feel substantial and familiar.

**Typical Fonts:** Classic typefaces (Georgia, Palatino, Baskerville), textured or embossed treatments — traditional, substantial, refined

**Typical Colours:** Natural palettes, leather, wood, metal tones, subtle gradients, realistic shadow colours

**Typical Graphic Elements:** Realistic textures, gradients and shadows, bevels and embossing, physical metaphors (buttons, switches, dials), rich detail work

### 11. Grunge

**One-Line Description:** Distressed rebellion — anti-aesthetic rawness signalling authenticity and edge.

**Core Feel:** Distressed, rebellious, anti-aesthetic, raw, authentic

**Typical Personalities:** Raw, Authentic, Anti-corporate, Rebellious, Underground

**Why This Match:** Grunge signals rejection of mainstream polish. Brands that celebrate imperfection and subcultural credibility.

**Typical Fonts:** Distressed typefaces, hand-drawn or stencil styles, typewriter and stamped fonts — worn, imperfect, raw

**Typical Colours:** Muted and dirty palettes, black and desaturated tones, rust, olive, washed-out colours, high contrast with grime

**Typical Graphic Elements:** Distressed textures, torn paper effects, photocopied/xerox aesthetic, collage and layering, handwritten elements

**Typical Fonts:** Japanese characters mixed with Latin, retro computing fonts, chrome and gradient text effects — stylised, distorted, retro-digital

**Typical Colours:** Cyan, magenta, pink, purple; sunset gradients; neon tones; pastel pinks and blues

## Expert Override Protocol

A designer or design-literate user can respond to the derived position in three ways:

### 1. Accept the Derivation

Proceed with the framework's derived position and the three variation strategies. This is the default and the path the framework is built for.

### 2. Request Adjustment to a Free Axis

_"I think the resonance position is right but I want to explore harder on the Restrained side than the current strategies offer."_

The framework re-derives the variation strategies with adjusted weighting on the named free axis. Locked axes are not modified.

### 3. Propose Override to a Locked Axis

_"I think this brand should actually be Cool, not Warm — the Module 05 derivation has it wrong."_

This is a Module 05 conversation, not a Module 10 conversation. The override is rejected at the Module 10 layer and the user is routed back to Module 05 for the conviction re-derivation. The framework does not permit Module 10 to override Module 05 — that would invert the derivation chain.

### Conflict Warning

If a user's proposed adjustment would push the derived position outside the conviction-anchored locked range, the framework surfaces:

> _"Warning: this adjustment would put the brand at a resonance position that contradicts Module 05's [trait]. Specifically:_
>
> _- Module 05 Personality 'X' typically derives to [locked axis position]_
> _- Your proposed adjustment lands at [conflicting position]_
> _- This may indicate Module 05 needs revisiting, or that the adjustment is a stylistic preference not anchored in conviction_
>
> _Options:_
> _1. Return to Module 05 and re-derive_
> _2. Stay within the conviction-anchored range_
> _3. Document the override as a known overclaim with a planned correction date_"

## Locking the Layered Output

When the layered derivation is complete, the output is locked across the framework:

1. **Layer 7 output document** (Style System or Operating Constitution) becomes the canonical reference
2. **All 10B outputs** derive from this document, never from upstream layers directly
3. **All medium-specific derivatives** (DESIGN.md, brand kit, print spec, image-prompt modifier library) cite the Layer 7 source
4. **Future revisions** propagate forward through every dependent layer — changes to Module 05 require re-running the full derivation chain, not patching downstream artefacts

---

## If Stuck

If the layered derivation produces output that feels arbitrary, generic, or disconnected from the brand, the most likely cause is **skipping a layer**. Check in order:

| Layer | Check |
| --- | --- |
| Layer 1 | Is Module 05 genuinely anchored, or aspirational? Run Gate 0 again. |
| Layer 2 | Have you stated focal/containment/breathing as principle, or skipped to specifics? |
| Layer 3 | Have you placed the brand on all six pairs explicitly? |
| Layer 4 | Have you translated commitments into observable behaviours and tests without jumping to values? |
| Layer 5 | Has the brand's sector, medium, and audience been applied to narrow the ranges? |
| Layer 6 | Have you declared Expressive or Controlled, or left it implicit? |

A skipped layer leaves the derivation incomplete and turns the output into a disguised selection. Complete that layer, then re-derive each layer that follows.
