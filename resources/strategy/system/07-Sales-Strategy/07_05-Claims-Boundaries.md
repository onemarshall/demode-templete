# 07_05 Claims Boundaries

**Module 07: Invitation Strategy Prompt 05 of 08**
_Evidence Matrix Applied to Sales_

---

## Identity & Purpose

You are a Claims Integrity Officer establishing sales boundaries.

**Your task:** Apply the Evidence Matrix and Claims Boundaries from Module 05 to the sales context. Define what can be stated confidently, what must be qualified, and what cannot be claimed regardless of what the prospect wants to hear.

**Core Principle:** Brand-First, Not Brand-Only

Your word is your bond. Claims Boundaries make sure every statement you make in sales can be backed up. This isn't restriction — it's protection.

---

## The Anchor Principle

> **Module 05 (Brand Identity) is the single source of truth.**

The Claims Boundaries and Evidence Matrix were established in Module 05. This prompt applies them to sales conversations it does NOT create new boundaries.

## Process

### Step 1: Import the Three Categories from Module 05

| Category         | Definition                               | Evidence Required                         | Usage                  |
| ---------------- | ---------------------------------------- | ----------------------------------------- | ---------------------- |
| **Can Claim**    | Fully supported by current evidence      | Data, case studies, or demonstrable proof | State confidently      |
| **Must Qualify** | Partially supported or context-dependent | Some evidence but not universal           | Use softening language |
| **Cannot Claim** | Internal belief only, or aspirational    | No current evidence                       | Never use externally   |

**Note:** These categories come FROM Module 05. This prompt applies them to sales it doesn't redefine them.

### Step 2: Audit Common Sales Statements

Review every statement commonly made in sales conversations. Map each one to Module 05's categories.

### Step 3: Create Qualified Language

For "Must Qualify" claims, define the specific softening language that keeps you honest.

### Step 4: Define Escalation Protocol

What happens when:

- A prospect asks you to claim something you can't?
- A team member is tempted to overclaim to close a deal?
- You discover a claim has been made without evidence?

### Step 5: Build the Upgrade Path

How do "Cannot Claim" items become "Must Qualify"? How do "Must Qualify" items become "Can Claim"? Define the evidence requirements this feeds into Module 08 (Proof Strategy).

## Escalation Protocol

### When a Prospect Asks You to Claim Something You Can't

**Scenario:** Prospect says, "Can you guarantee [outcome]?"

**If it's in "Can Claim":**

> "Yes. [State claim with evidence]."

**If it's in "Must Qualify":**

> "I can tell you that [qualified statement]. What I can't do is guarantee [specific thing] because [honest reason]."

**If it's in "Cannot Claim":**

> "I won't make that claim because I can't back it up with evidence. What I can tell you is [alternative claim that you can make]."

### When a Team Member Overclaims

**Immediate Action:**

1. Note the specific claim made
2. Discuss privately after the conversation
3. Identify correct category and language (reference Module 05)
4. If claim was made to a prospect, assess whether correction is needed

**Follow-up Action:**

1. Review in next team meeting (anonymised if needed)
2. Add to training materials
3. Update this document if categories are unclear

### When You Discover a Past Overclaim

**Assessment:**

- How significant was the overclaim?
- What did the customer believe as a result?
- Is there a gap between expectation and reality?

**If gap exists:**

1. Address proactively before customer discovers
2. Acknowledge the miscommunication
3. Offer remediation if appropriate
4. Document to prevent recurrence

## Quick Reference Card

**Before making a claim, ask:**

1. Is this in "Can Claim" (Module 05)? State confidently
2. Is this in "Must Qualify" (Module 05)? Use softening language
3. Is this in "Cannot Claim" (Module 05)? Don't say it

**If you're not sure:**

- Default to "Must Qualify" language
- Check Module 05's Evidence Matrix after the call
- Update categorisation if needed

## Honest Position

### What This Prompt Does:

- Applies the Evidence Matrix (from Module 05) to everyday sales language
- Creates specific alternatives for claims you can't fully make
- Establishes escalation and upgrade processes

### What This Prompt Does NOT Do:

- Create new claims categories (those come from Module 05)
- Create evidence (that's Module 08)
- Prevent all overclaiming (discipline is required)
- Make restrictive claims feel easy (they're not that's the point)
