# Quality Gates: Founder Convictions

> **Client-language translation gate:** Apply `FW_27` before passing a client-facing output. Fail if a client has to decode excavation or framework terminology to state the conviction, evidence and next decision.

> **Meaning Record gate:** Apply `FW_35`. Fail a locked load-bearing conviction unless its exact words, lived situation, proposed meaning, opposite, boundary and founder confirmation are recorded.

## FW_32 accountability gate

Pass only when:

- accepted anchors retain exact decision IDs;
- material assumptions record owner/basis/test/confidence/expiry; and
- Foundation Use Contract source fields cover uncoached explanation, downstream inheritance, real use, founder reconstruction and contradictory briefing.

Fail any implied outcome promise, invented baseline, monetary estimate or collapsed approval state.

**Module 01 DeMode™**
_Ensuring Your Foundation Is Solid_

## What This Document Does

This document defines the pass/fail criteria for Module 01. Before proceeding to Module 02 or locking outputs in the Handoff Pack, your work must meet these standards.

**How to use:** Review each gate below after completing the conversation and Output D in `01-Prompt.md`. If you fail any gate, return to the relevant governed prompt section and strengthen the weak elements before proceeding.

**Reality check:** These gates are strict because downstream modules depend on a real foundation. If your conviction isn't solid, everything built on it will shift under pressure.

## Cross-Module Canonical Gates — Module 01's Role

Under `framework/FW_17-Cross-Module-Quality-Gates.md`, Module 01 supplies the **source-of-truth** for two gates used by downstream modules:

- **CMQG_01 Conviction Trace** — Module 01 is the source for the five conviction elements and Core Belief. Every locked output of Modules 03, 05, 06, 07, 08, 09, 10, 11 traces back to the relevant locked upstream artefact (Module 01 for conviction elements, Module 05 for deployment Claims Boundaries and translated language, Module 04 for route). Module 01's job is to produce conviction elements that *can be traced to* — locked, named, quotable.
- **CMQG_02 Claims Boundary Compliance** — Module 01 produces Draft Claims Boundary Inputs. Module 05 locks the active Claims Boundaries that downstream modules comply with. Module 01's job here is to produce draft inputs that *can become* compliant boundaries — using the canonical three-category structure (Can Claim / Must Qualify / Cannot Claim) verbatim.
- **CMQG_03 Upstream Acknowledgment Satisfaction** — N/A. Acknowledgments originate at Module 02 Gate 5.
- **CMQG_04 Translation Trace** — N/A. Module 01 is discovery, not translation.

Module 01 is responsible for **the quality of the inputs it supplies**. It drafts Claims Boundary Inputs; Module 05 locks the deployment Claims Boundaries. Quality Gate 0 below tests that responsibility.

## Source Authority Check (Before Gate 0)

**Criteria:** The person or people authorising the conviction have been named, and the Handoff Pack reflects their authority honestly.

| Situation | Pass | Fail |
| --- | --- | --- |
| Single founder / owner | The named source owns the Core Belief and can commit to the Non-Negotiable. | A facilitator, spouse, advisor, or team member answers for them. |
| Practitioner or internal team for client | The conviction source has answered directly, or a recorded interview with them is the source material. | The practitioner writes what they think the client believes. |
| Co-founders / leadership team | Each source has run the conversation separately, shared alignment is named, and unresolved divergence is either resolved or explicitly prevents lock. | A blended belief is manufactured from compromise, politeness, or committee wording. |

**Test:** Ask, "Who can sign this Core Belief and be held to the Non-Negotiable when it costs money?" If the answer is unclear, Module 01 is not lockable yet.

**Action if Fail:** return to the source conversation. For co-founders, map alignment and divergence before synthesis. For practitioners, bring the conviction source into the room or work from a recorded interview. Do not seal the Handoff Pack until source authority is clear and any disagreement is resolved.

## Quality Gate 0: Lockability + Verbatim Quotability (Module-Start Output Contract)

**Criteria:** Every output Module 01 produces — Hidden Truth, Core Belief, Broken Thing, Non-Negotiable, Hard-Won Teaching, Legacy, Draft Claims Boundary Inputs — must be **lockable** (committed to without further iteration once the Handoff Pack is sealed) and **verbatim-quotable** (downstream modules can quote the text directly without paraphrase or interpretation).

Downstream Step 0s (per FW_15) and Translation Discipline (per FW_16) require *verbatim* quotations of Module 01 outputs. Those outputs must therefore be exact, quotable text. Impressions, metaphors that need decoding and paraphrases leave later modules unable to proceed beyond pre-lock concession—or tempt them to substitute positioning language. This gate prevents both problems.

| Element | Lockable Pass | Verbatim-Quotable Pass | Fail Mode |
| -- | -- | -- | -- |
| **Hidden Truth** | Single sentence the builder commits to without further iteration | Downstream Module 02 Step 0 / Module 03 Step 1 can quote this sentence directly | Impressionistic phrasing; *"something about..."*; metaphor that needs decoding |
| **Core Belief** | Format: *"I believe that [X], and therefore I must [Y]"* — both halves locked | Module 02 / 03 / 05 can quote both halves directly | Either half left as placeholder; either half too generic to anchor downstream identity |
| **The Broken Thing** | Single named industry practice the conviction stands against | Module 05 (Values) can quote the Broken Thing as "what each Value rejects" | List of grievances rather than a named target; too broad to operationalise into a Value rejection |
| **Non-Negotiable** | Single sentence stating the owned commitment and what it rules out; record a relevant past costly choice when available, or mark it prospective with a named trade-off and capture/review plan | Module 03 Step 7 + Module 05 (Values "what each protects") can quote the commitment and its evidence status | No decision force or test path; past enactment or cost is claimed without evidence; prospective commitment is presented as demonstrated adherence |
| **Hard-Won Teaching** | Single sentence naming what the builder has earned through practice and can now transfer | Module 01 Manifesto, Module 05 story, and Module 08 proof strategy can quote the earned teaching directly | Generic advice; lesson consumed from elsewhere; no visible link to practice |
| **Legacy** | Single sentence picturing the new reality if the conviction succeeds | Module 05 (Vision) can quote directly; Module 06 Statement 7 (Advocacy) can derive from it | Grandiose without specifics; externally validation-dependent |
| **Draft Claims Boundary Inputs** | Three populated lists (Can Claim / Must Qualify / Cannot Claim) — each list non-empty | Module 05 can lock active Claims Boundaries from these inputs without re-inventing the evidence discipline | Categories collapsed; "Must Qualify" items written so they read like "Can Claim"; "Cannot Claim" left empty |

**Verbatim Test:** open the Module 01 Handoff Pack alongside a hypothetical Module 02 Step 0 run. For each Module 01 output, can the Module 02 facilitator copy-paste the text directly into the Step 0 verbatim block without rewriting? If not, the output fails this gate — strengthen the wording before locking.

**Action if Fail:** rewrite each failing element so it can be quoted verbatim *before* sealing the Handoff Pack. Do not lock an output that later modules cannot quote directly.

### Substantial Outputs — also covered by Quality Gate 0

Module 01 also produces three substantial outputs. They supply the depth, context, voice and evidence behind the seven short anchor / input statements. The Lockability + Verbatim Quotability contract applies to these too, with criteria suited to each output.

| Substantial Output | Lockable Pass | Verbatim-Quotable Pass | Fail Mode |
| -- | -- | -- | -- |
| **Builder Manifesto** | Full narrative document per `01-Prompt.md` Output B — every section populated, not sketched | Module 05 brand story can quote any paragraph directly; Module 03 conviction grounding can cite specific sections | Bullet points only; sections labelled but content thin; placeholder text remaining; reads as outline not narrative |
| **Natural Language Bank** | Eight categories populated; minimum 3 verbatim phrases per category; energy pattern noted per phrase | Modules 05–10 voice / tone / copy work can use captured phrases verbatim | Paraphrased phrases (not from the actual conversation); categories left empty; energy patterns omitted (just a phrase list with no voice information) |
| **Evidence Matrix** | 3+ load-bearing claims identified; each claim paired with at least one specific evidence item; each evidence item categorised per `framework/FW_13-Facts-Anchor-Protocol.md` | Module 03 proof commitments can cite specific evidence items by category; Module 02 Vulnerable Default test can cite evidence by claim | Generic evidence (e.g. *"customer feedback"* with no specific instance); category-inflation (personal observation labelled as third-party research); claims without evidence |

**Verbatim Test for substantial outputs:** open the Handoff Pack alongside hypothetical Module 05 brand-story / Module 06 voice-work / Module 03 proof-commitment runs. Can each downstream facilitator find specific, citable material in the relevant substantial output without having to re-elicit content from the builder? If they would have to go back to the builder for context the Manifesto / Bank / Matrix should have provided, the output fails this gate.

**Action if Fail:** return to the Processing the Conversation / AI Synthesis step in `01-Prompt.md`. The synthesis step is where these substantial outputs get built from the recorded conversation; if they're thin, the synthesis was thin and needs re-running with deeper extraction from the transcript.

**Why this matters:** Conviction Trace (CMQG_01) checks the seven short anchor / input statements. Module 05's brand story, Modules 05–10's voice work and Module 03's proof commitments also need the three substantial outputs. Both sets must be locked before Module 01 seals its Handoff Pack.

## Quality Gate 1: Conviction Depth

**Criteria:** Your conviction elements must show depth, not surface answers.

| Element                | Pass                                                                                                                               | Fail                                                                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **The Broken Thing**   | You feel heat when talking about it; you could rant for 20 minutes without notes; you've felt this way for over two years          | Generic complaints ("Customer service is bad"); borrowed anger (what others complain about); safe criticisms that won't offend |
| **The Hidden Truth**   | You can point to specific experiences that taught you this; it's grounded in practice, not just observation                        | Generic insights ("Hard work pays off"); something you read vs. something you lived; no specific examples                      |
| **The Non-Negotiable** | You can name a relevant past choice and cost when one exists; otherwise you can name the prospective trade-off, what decision it governs, and how enactment will be captured and reviewed | No plausible trade-off or decision; a prospective commitment is presented as already enacted |
| **Hard-Won Teaching**  | You can name what practice taught you, what it cost to learn, and why you can now transfer it to someone else                      | Motivational advice; borrowed lesson; no visible route from practice to teaching                                                |
| **The Legacy**         | You can describe specific people whose lives would be different; it's ambitious yet specific; you'd pursue it even if unattributed | Grandiose ("Change the world") without specifics; externally validated (requires fame); vague ("Help people") without detail   |

**Test:** Read the exact words and source evidence with the accountable owner. Ask what decision the commitment governs, what evidence supports or challenges it, and what would prompt revision. A second reader may challenge the interpretation; neither agreement nor hesitation certifies inner sincerity.

**Action if Fail:** Return to the governed excavation in `01-Prompt.md` and use its deepening prompts.

### Handoff usability checks

- **Market-Deployable Hidden Truth:** preserves the exact semantic claim of the locked Hidden Truth, is concrete enough for Module 02 to investigate and contains no positioning, value proposition or audience promise. A meaning-changing translation fails this subordinate handoff check and is recorded as `translation-failure`; it does not fail the locked Hidden Truth or Module 01.
- **Public Record Readiness:** records whether the conviction could eventually be understood and associated with the builder by strangers. This is not a conviction-validity gate and cannot fail the module merely because the builder has no audience or public record.

These checks prepare the handoff. They do not blend builder-side and market-side validation. Module 01 tests the builder's evidence; Module 02 tests the market implication.

## Quality Gate 1.5: Recognition Verdict

**Criteria:** The Mirror Test has produced a Recognition verdict — Surfaced, Buried, or Empty Ground — and the Handoff Pack records what that verdict means for lockability.

| Verdict | Meaning | Gate Action |
| --- | --- | --- |
| **Surfaced** | The conviction comes cleanly in the builder's own language, and the Mirror partner recognises it as theirs | Proceed if Gates 0-7 also pass |
| **Buried** | The substance is present, but the language is not formed enough to lock | Continue excavation before sealing the Handoff Pack |
| **Empty Ground** | The answers are generic, borrowed, contradictory, or unsupported by practice | Do not lock downstream strategy on this recognition yet |

**Test:** Ask the Mirror partner: "Did this sound like the builder, or did it sound like performance?" Then record the verdict and the reason in the Handoff Pack.

**Action if Buried:** Return to the question set that produced the strongest fragment. Use follow-up, silence, and concrete examples until the answer becomes sayable.

**Action if Empty Ground:** Do not treat this as rejection. Treat it as routing. The builder may need more practice, stronger evidence, a better-fitting business frame, or a different source conversation before Module 01 can lock.

See `../framework/FW_22-Recognition-Method.md` for verdict definitions and the full Recognition Method.

## Quality Gate 2: Coherence Check

**Criteria:** Your five conviction elements must tell one story (Broken Thing, Hidden Truth, Non-Negotiable, Hard-Won Teaching, Legacy — the fifth added 2026-05-23).

| Pass                                                                                                                                                           | Fail                                                                                                  |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| The Hidden Truth explains why the Broken Thing exists; the Hard-Won Teaching shows how the builder earned the insight; the Non-Negotiable protects the Hidden Truth; the Legacy is what happens when the Broken Thing is fixed | Elements feel disconnected; no clear throughline; one element contradicts another without explanation |

**Test:** Write one sentence connecting all five: "Because I see [Hidden Truth] about [Broken Thing], I learned [Hard-Won Teaching], and I won't [Non-Negotiable], so I can build [Legacy]." If this feels forced, you fail.

**Action if Fail:** Identify the disconnected element and revisit its governed questions in `01-Prompt.md`. Use the contradiction prompts to resolve tension.

## Quality Gate 2.5: Conviction Coherence Test

**Criteria:** You can express the full conviction in **five** connected sentences using the Conviction Coherence Test shape. Expanded from four to five sentences on 2026-05-23 to include the Hard-Won Teaching (CF-5), per book Ch.6 chapter spine.

| Sentence   | Required Mapping       | Pass                                                                                                                              | Fail                                                                          |
| ---------- | ---------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **Claim**  | Broken Thing           | Names the core break in one sharp sentence                                                                                        | Generic complaint or no clear point                                           |
| **Feel**   | Hidden Truth           | Makes the truth felt with a concrete image/moment                                                                                 | Purely analytical or borrowed language                                        |
| **Proof**  | Non-Negotiable         | Records past enactment and cost where available, or a prospective commitment with a named trade-off and test plan | Unsupported claim of enactment; no decision force or review path |
| **Earned** | Hard-Won Teaching      | Names the specific thing paid for in experience; demonstrably underlies at least one of Claim / Feel / Proof (foundation layer)   | Generic motivational advice; consumed not earned; doesn't underlie the others |
| **Invite** | Legacy                 | States the specific commitment and what changes                                                                                   | Generic mission language anyone could claim                                   |

**Test:** Read the five sentences out loud in order (Claim → Feel → Proof → Earned → Invite). Ask: *"Do these sound like one person describing one conviction?"*

**Foundation-layer check (Earned-specific):** The Earned sentence is the *foundation underneath* the first three. After reading aloud, ask: *"Does the Earned sentence explain why you noticed the Claim, why the Feel feels the way it does, or why the Proof is non-negotiable to you specifically?"* If yes, the Teaching is load-bearing. If no, the Teaching the builder has named is a different teaching, not the load-bearing one — push for the deeper one.

**Action if Fail:**

- If Claim fails → return to Broken Thing prompts.
- If Feel fails → return to Hidden Truth prompts.
- If Proof fails → return to Non-Negotiable prompts.
- If Earned fails or doesn't underlie at least one of Claim / Feel / Proof → return to Hard-Won Teaching prompts (Phase 5.4).
- If Invite fails → return to Legacy prompts.

## Quality Gate 3: Prospective Constraint Test

**Criteria:** Before inspecting existing language or artefacts, the conviction must require at least one future choice and rule out at least one plausible alternative. Its Non-Negotiable and Legacy must be situated in this business's experience, practice and commitments. Competitor comparison can help reveal generic language, but it is not the validity test.

| Element          | Pass                                                                                                    | Fail                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| **Core Belief**  | It prospectively governs an identity-bearing choice and derives from the Hidden Truth | Generic enough that it cannot decide between plausible alternatives ("We help people succeed")             |
| **Purpose**      | Ties directly to your Core Belief; tells you what to do, not just hope for                              | Disconnected from conviction; a competitor with opposite beliefs could use it          |
| **Values**       | You can name what each value costs and rejects; you've demonstrated it when hard                        | Cost-free or universally agreed ("Integrity"); aspirational vs. demonstrated           |
| **Belief Shift** | The FROM belief is familiar (they hold it); the TO belief is liberating; you have evidence it works     | Too easy (they'd agree immediately); disconnected from Core Belief; unproven TO belief |

**Test A -- Before-the-Choice Test:** Without looking at the current artefact, name what the conviction requires and what plausible alternative it excludes. If the answer can be rewritten to justify any outcome after the fact, the element fails.

**Test B -- Same-Belief Test:** Some convictions are shared, such as "craft matters" or "customers deserve honest treatment". If your Hidden Truth is one of these, the Opposite-Belief Test is not enough. Ask whether a competitor who sincerely holds the same belief would produce the same Non-Negotiable and Legacy.

If so, the Hidden Truth alone is doing the work of differentiation. That distinction will collapse wherever others share it. Make the Non-Negotiable and Legacy specific to the line _you_ hold and the change _you_ are committing to.

**Action if Fail:** Revise generic elements using the differentiation deepening prompts in `01-Prompt.md`. If the source remains broadly shared, push the Non-Negotiable and Legacy to the specific decision and commitment this business owns rather than inventing opposition.

## Quality Gate 4: Claims Boundaries

**Criteria:** Your Evidence Matrix must show more "Can Claim" items than "Must Qualify" or "Cannot Claim."

| Pass                                                                                                         | Fail                                                                                                    |
| ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| Majority of claims are "Can Claim" (fully supported by evidence); clear plan to upgrade "Must Qualify" items | Majority are "Must Qualify" or "Cannot Claim"; no plan to gather evidence; overclaiming without support |

**Test:** Review `01-Prompt.md` Output D. Count items in each category. If "Can Claim" isn't the largest, or if any "Cannot Claim" items are used externally, you fail.

**Action if Fail:** Identify evidence gaps. For each "Must Qualify" or "Cannot Claim" item, define what evidence would move it to "Can Claim." Prioritise gathering that evidence before Module 07.

## Quality Gate 5: Conviction Trace

**Criteria:** Every element must trace back to your Core Belief with a clear connection.

| Pass                                                                                                        | Fail                                                                                                              |
| ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |

## Quality Gate 6: Self-Deception Check (Four Signals)

**Criteria:** Your conviction must light up on at least three of the four Realness Signals (see `01-Philosophy.md` > "The Four Signals of Real Conviction"). Zero-signal patterns are disqualifying; one-signal patterns require more work; two-signal patterns are borderline; three or four is pass.

| Signal            | Pass                                                                 | Fail                                                                           |
| ----------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **Temporal**      | The conviction predates this business, or predates this pivot        | Conviction appeared after the business decision AND has not since been tested  |
| **Sacrificial**   | You can name a specific time this belief cost you something real     | No cost ever, no imaginable scenario in which you'd pay one                    |
| **Experiential**  | The belief comes from practice -- something you learned in your body | Borrowed from a book, a podcast, or a peer; no embodied knowledge behind it    |
| **Psychological** | Answers feel uncomfortable; a trusted friend would recognise you     | Answers sound impressive but comfortable; it's what you think you _should_ say |

**Test:** Mark each signal Pass or Fail. Count Passes.

- **4 of 4 Pass:** Solid. Proceed.
- **3 of 4 Pass:** Pass. Note which signal didn't fire and why (often: Temporal on a mid-career pivot, or Sacrificial on a young conviction not yet tested). Document the gap rather than hiding it.
- **2 of 4 Pass:** Borderline. Do not proceed until at least one more signal fires. Go gather the missing evidence -- usually by running the belief into a situation that tests it.
- **1 of 4 or 0 of 4:** Fail. This is not yet conviction, or it is manufactured.

**A note on Temporal:** Recent conviction is not disqualifying on its own. Conviction genuinely emerges through experience -- an ethical crisis, a professional failure, a sudden clarity. The failure pattern is "recent AND untested AND conveniently matches a business case you already wanted to make." Recent alone is just young.

**Action if Fail:** Seek external feedback. Share Set 1 answers with a trusted friend or advisor. Ask: "Does this sound like me?" If not, revisit questions with their input. For missing Sacrificial signal, consider: what specific commitment could you make in the next 90 days that would test the belief at real cost? That commitment becomes the first proof action in Module 11.

## Quality Gate 7: Distillation Back-test

**Criteria:** Module 01's primary load-bearing outputs — the **Core Belief sentence** and the **Builder Manifesto** — must each compress to their load-bearing minimum without flattening the variables they depend on.

Apply the Distillation Cycle (`framework/FW_14-Distillation-Cycle.md`) to Module 01's outputs. If the back-test fails, find out whether the problem is in the source—the Manifesto or Core Belief—or in a compression that cut too much.

**What gets back-tested:**

- **The Core Belief sentence** — already a compression (single sentence in the *"I believe that [truth], and therefore [action]"* shape). The back-test verifies it preserves the five conviction elements (Broken Thing, Hidden Truth, Non-Negotiable, Hard-Won Teaching, Legacy) and their directional relationship.
- **The Builder Manifesto** — when compressed to its load-bearing minimum (typically a paragraph or the five-sentence Conviction Coherence Test shape per Gate 2.5), it must still preserve the same five-variable structure.

**The three tests** (per `framework/FW_14-Distillation-Cycle.md`):

1. **Survives hostile reading.** Read the compression aloud to someone who would prefer your conviction were softer. If they can misread it in a way the full Manifesto wouldn't allow, you've gone too far. Restore enough structure to close the misreading.
2. **Preserves the variables the source depends on.** The five elements must remain distinct in the compression — not collapsed into a single thing. The directional relationship (Hard-Won Teaching underlies Hidden Truth and often the Broken Thing too; Hidden Truth explains the Broken Thing; Non-Negotiable protects the Hidden Truth; Legacy is what changes when the Broken Thing is fixed) must remain readable.
3. **Traces cleanly to the conviction.** The compression must connect to the substrate (your Pre-Foundation answers and lived experience) without drift.

**Test:** Write the Core Belief sentence on one line. Below it, write the five-sentence Conviction Coherence Test (Claim / Feel / Proof / Earned / Invite). Now read both compressions and ask:

- Does the compression let a hostile reader misread it? (Test 1)
- Are all five elements still doing distinct work, or has one swallowed the others? Specifically: does the Earned sentence demonstrably underlie at least one of Claim / Feel / Proof? (Test 2)
- Does the compression still trace to something you've actually lived? (Test 3)

A compression that fails any of the three is data, not failure.

**Action if Fail — classify which kind of flaw:**

| If the compression revealed...                                                                | Fix lives in...                                                                                |
| --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| The Manifesto carrying soft language or unfenced claims the compression sharpened by removing | The Manifesto (rewrite the source at load-bearing minimum)                                     |
| A variable that was always collapsed in the Manifesto and the compression made it visible     | The Manifesto (split the compound variable; see Gate 2 Coherence Check)                        |
| The Manifesto claiming more than the substrate supports                                       | The substrate work (return to `01-Prompt.md` and gather the missing evidence) |
| The compression flattened a real distinction that the Manifesto holds correctly               | The compression only (restore the distinction; the Manifesto is unchanged)                     |
| A load-bearing qualifier dropped during compression                                           | The compression only (restore the qualifier)                                                   |

Most failures here will be source-side. The compression is doing its job by exposing them.

**Upstream propagation:** If the back-test exposes imprecision in the Manifesto or Core Belief, return to the excavation in `01-Prompt.md`. If the underlying lived material is missing, return to the Pre-Foundation answers. Re-run Gates 1–6 after any upstream fix.

**Downstream propagation:** If the back-test changes the Manifesto or Core Belief, the change must propagate to every module that imports from Module 01:

- **Module 02** — Core Belief is the lens for market analysis; updated Core Belief means re-running the terrain read.
- **Module 03** — Conviction Grid quadrants derive from the Hidden Truth and Broken Thing; revise grid.
- **Module 05** — Brand anchor imports from the Manifesto; re-lock affected brand elements.
- **Module 07** — Evidence Matrix / Claims Boundaries inherit; revise objection-handling.
- **Module 08** — Proof pillars derive from what's claimed; revise pillars if claims shifted.

Do not lock the Handoff Pack until propagation downstream has been mapped, even if the back-test only affected this module.

**Final Checkpoint note:** Gate 7 runs *after* Gates 1–6 have passed. The earlier gates verify the substance is strong; Gate 7 verifies it survives compression — which is what every downstream module will do to it.

## Final Checkpoint

**All Gates Passed:** You are ready to lock outputs in `01-Handoff-Pack.md` and proceed to Module 02. Your conviction foundation is solid enough to build on.

**Any Gate Failed:** Do not proceed. Address failed gates using the specified actions. Building on a weak foundation will cause downstream strategy to shift under pressure.

**Honest Position:** Failing a gate is not failure -- it's information. Better to strengthen now than discover gaps in Module 07 when selling something you don't fully believe.

**What these gates do NOT verify:** Module 01 records an owned source, its applied commitments and the available evidence. It cannot certify inner sincerity or establish that a commitment is true.

Module 02 (Market Reality Check) tests the Hidden Truth against real industry artefacts. A coherent but unverified Hidden Truth can pass Module 01, but remains provisional until Module 02 passes. Coherence alone cannot establish market correctness.
