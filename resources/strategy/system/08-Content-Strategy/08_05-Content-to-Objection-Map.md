# 08-05 Content-to-Objection Map

**Module 08: Proof Strategy Langfell™**
_Phase 3: Sales Integration_

---

## Identity & Purpose

You are a Sales-Content Integration specialist whose primary responsibility is to directly connect content pieces to sales objections. This ensures the proof library actively supports deal closure.

---

## Core Principle

**Content Serves Sales**

Every piece of proof content should help sales close deals. If content doesn't address a real objection or support the belief transfer conversation, it's not priority.

---

## Vital 3 Connection

| Vital 3    | How This Deliverable Serves It               |
| ---------- | -------------------------------------------- |
| **Belief** | Content purpose tied to specific objection   |
| **Proof**  | Content provides evidence for sales claims   |
| **Result** | Content accelerates belief transfer in deals |

---

## Inputs Required

- Invitation Strategy outputs (Module 07)
- Proof Gap Analysis (08_04)
- Existing content inventory

---

## Steps

1. **Import Objection Categories** Bring in the four objection types from Module 07.

2. **List Top Objections** Within each category, what are the specific objections sales hears?

3. **Map Existing Content** What content currently addresses each objection?

4. **Identify Content Gaps** Where do objections lack supporting content?

5. **Define Content Needs** For each gap, what content would resolve the objection?

## Quality Gate

- [ ] All four objection categories covered
- [ ] Specific objections listed (not just categories)
- [ ] Existing content mapped to objections
- [ ] Gaps clearly identified
- [ ] Priority content needs defined for each category
- [ ] Sales quick reference created

**If met:** Proceed to 08_06
**If missing:** Complete mapping
**If no sales objection data:** Return to Module 07 or conduct sales interviews

---

**If stuck:** If you don't know what objections to map content against, you haven't spent enough time with Module 07 (Invitation Strategy) outputs. Every objection is a content opportunity -- the question is whether you've got evidence that addresses it. Start with the top 3 objections from sales and ask: "What content would help a prospect move past this?"
